# Beast Pit site

Static pages for the Beast Pit Play Store listing: a landing page and the privacy policy.

- `index.html`: landing page
- `privacy/index.html`: privacy policy (paste its public URL, e.g. `https://<user>.github.io/<repo>/privacy/`, into the Play Console)

Keep `privacy/index.html` in sync with `docs/PRIVACY_POLICY.md` in the game repo.

Publish with GitHub Pages: push this repo to GitHub, then Settings > Pages > deploy from branch `main`, folder `/ (root)`.
